# TLI Tracker

*Torchlight: Infinite* 모바일 클라이언트의 파밍 수익을 실시간으로 집계하는 안드로이드 오버레이 앱.

게임을 수정하거나 메모리를 읽지 않는다. 게임이 스스로 남기는 로그 파일만 읽어 획득·소비 아이템을
추적하고, 시세를 곱해 수익을 계산한다.

## 무엇을 하나

- **회차별 수익 집계** — 맵 열기를 경계로 회차를 끊어 막대 그래프로 표시. 막대를 누르면
  그 회차에서 얻은 아이템 목록과 단가를 볼 수 있고, 잘못 잡힌 회차는 삭제할 수 있다.
- **게임 위 플로팅 HUD** — 경과 시간, 총 수익, 시간당 수익, 이번 맵 손익을 실시간으로.
  나침반·비콘 소비는 빨간 마이너스로 표시된다.
- **시세 두 곳 중 선택** — ETor(시즌 스냅샷, 전 아이템) / TTD(ttdiablo.com 한국 시세).
- **경매장 조회 반영** — 게임 안에서 시세를 조회하면 그 호가 평균이 스냅샷보다 우선 적용된다.

## 요구사항

| 항목 | 요구사항 |
|---|---|
| Android | 10 (API 29) 이상 |
| 게임 | `com.xd.TLglobal` · `com.xd.TLglobalTap` · `com.xindong.torchlight` |
| [Shizuku](https://shizuku.rikka.app/) | 필수. root 는 불필요 |

Android 11 부터 다른 앱의 `Android/data/` 는 일반 앱이 읽을 수 없다. Shizuku 가 shell(uid 2000)
권한으로 로그 파일을 대신 읽어준다.

## 설치와 사용법

설치, 최초 설정, HUD 사용법, 문제 해결은 **[INSTALL.md](INSTALL.md)** 참고.

> 앱을 처음 켰을 때 (또는 세션을 리셋했을 때) 게임 인벤토리에서 **가방 정렬**을 한 번 눌러야
> 집계가 시작된다. 게임이 그 순간 가방 전체 스냅샷을 로그에 남기고, 앱은 그걸 기준값 삼아
> 이후의 획득·소비량을 계산한다.

## 개인정보 / 보안

- **아웃바운드 요청은 시세 API 두 곳과 업데이트 확인뿐**이다. 계정·아이템·플레이 데이터는
  어디로도 보내지 않는다.
  - `etor-zero.981001.xyz` — 시즌 시세 (시즌 ID 만 전송)
  - `ttdiablo.com` — 한국 시세 (정적 JSON)
  - `api.github.com` — 앱 시작 시 1 회, 새 버전 확인
- Shizuku 로 실행되는 `UserService` 는 **읽기 전용**이다. 파일 생성·수정·삭제 op 가 없고,
  경로는 게임 데이터 디렉토리로 화이트리스트되어 있다.
- 위치·카메라·마이크·전화 상태·광고 ID 권한은 **선언 자체를 하지 않는다**.
- 집계 결과는 기기 안에만 있다.

## 업데이트

앱 시작 시 GitHub Releases 를 1 회 조회해 새 버전이 있으면 배너로 알린다. **설치는 하지 않는다** —
자동 설치를 하려면 `UserService` 에 APK 설치 능력을 줘야 하는데, 읽기 전용 원칙을 지키기 위해
그 경로는 열지 않았다. 자동 업데이트를 원하면 [Obtainium](https://github.com/ImranR98/Obtainium)
같은 도구에 이 저장소를 등록하면 된다.
